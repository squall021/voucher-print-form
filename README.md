# 憑證黏存單列印工具

使用原生文字與 HTML 表格製作的 A4 憑證黏存單，填寫後可直接在空白 A4 紙上列印完整表單。

## 功能

- 單位、活動名稱、年月日與經手人填寫。
- 最多 9 筆明細，金額自動加總至合計欄。
- 廠商名稱填寫，長文字依欄寬自動縮小。
- 收款（現金、支票、匯款帳號、其他）、沖銷（預支款、申請差額、繳回差額）、付款（現金、支票、匯款帳號）每列各自單選，選「不勾選」可取消該列勾選。
- 備註選項與對應輸入欄放在同一列，選取後啟用帳號、說明、金額或支票號碼欄。切換選項時保留文字，未選項目的文字不顯示於預覽或列印；草稿、版本及備份仍保留這些文字。
- 長文字依欄寬自動縮小。
- 在目前瀏覽器自動儲存資料。
- 電腦雙欄版面可分別捲動左側填寫區與右側預覽區；手機與窄視窗維持上下排列、整頁捲動。
- 本機黏存單紀錄庫：編號、搜尋、日期篩選、載入修改與重新列印。
- 每次儲存修改保留舊版本；內容未改變時不會重複建立版本。
- 分別記錄「開啟列印」與由使用者確認的「已列印」。
- JSON 備份匯出／匯入，保留全部版本及列印紀錄，重複匯入會合併。
- 原生文字、表格與框線輸出，不使用圖片底圖。
- 列印使用固定毫米尺寸，避免螢幕預覽的縮放影響列印。

## 使用方式

直接開啟 `index.html`，或將本專案放到靜態網站服務。檔案須保持在同一個資料夾。

填寫後，按「儲存並列印」，系統會先將當下內容存入紀錄庫，才開啟列印視窗。只要存檔時，按「儲存紀錄」。

放入空白 A4 紙。列印設定：A4、直式、比例 100%、邊界「無」，關閉頁首及頁尾。

## 黏存單紀錄庫

按「紀錄庫」可依編號、單位、活動、經手人、明細或儲存日期查詢。每張黏存單會產生以臺灣日期為準的編號，例如 `20261005-001`。

- **載入修改**：選擇版本後載入表單，修改並儲存時保留為新版本。
- **重新列印**：以選定版本重新列印，保留本次開啟列印的時間。
- **標記已列印**：確認紙張成功印出後，標記該版本最近一次尚未確認的列印紀錄。
- **新增黏存單**：開始另一張單，不會刪除歷史紀錄。
- **刪除**：刪除此張單的全部版本及列印紀錄，刪除前請先備份。

取消或關閉列印視窗時，紀錄仍保留。瀏覽器不能確認實體印表機是否印出紙張，因此不會自動標記為成功列印。使用瀏覽器 Ctrl+P／列印選單時也會嘗試保存當下內容；建議使用「儲存並列印」，確保紀錄儲存成功後才列印。

## 備份與換電腦

在紀錄庫按「匯出備份」，下載包含全部黏存單、各版本及列印紀錄的 JSON 檔。建議定期保存至自己的備份資料夾。

換電腦後，開啟相同工具網址，進入紀錄庫並按「匯入備份」。匯入會合併相同紀錄；舊備份不會移除較新的版本。若不同紀錄剛好使用同一編號，匯入會重新編號並保留原編號資訊。同一版本的內容若不一致，整批匯入會停止，原資料不變。

新版可匯入原有第 1、2 版備份格式，缺少的廠商及備註欄位會留空，原有現金或匯款勾選會保留。備份匯出使用第 3 版格式，保留全部勾選欄位；請使用新版工具匯入。

舊紀錄若同一列含多個勾選，載入時會依表單順序保留第一個選項，並提示確認。原紀錄不會被改寫；儲存或重印轉換後的內容會保留為新版本。

目前草稿保存在 localStorage；紀錄庫保存在 IndexedDB。資料只在目前裝置、瀏覽器及網址下，不會上傳至 GitHub，也不會跨電腦同步。清除網站資料會清除草稿與紀錄庫；請以匯出檔保留備份。

## GitHub Pages

在專案的 Settings → Pages 選擇 Deploy from a branch，再選擇 `main` 與 `/(root)` 並儲存。是否可啟用依專案權限與 GitHub 帳號方案而定。

## 檔案

- `index.html`：填寫介面及完整表單。
- `styles.css`：預覽與 A4 列印樣式。
- `app.js`：填寫、明細、加總、勾選與本機儲存。
- `records.js`：紀錄庫、版本、列印紀錄及備份合併。

此版本保留原有 A4 列印修正，並加入本機紀錄庫。
