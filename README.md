# 憑證黏存單列印工具

使用原生文字與 HTML 表格製作的 A4 憑證黏存單，填寫後可直接在空白 A4 紙上列印完整表單。

## 功能

- 單位、活動名稱、年月日與經手人填寫。
- 最多 9 筆明細，金額自動加總至合計欄。
- 現金或匯款帳號勾選。
- 長文字依欄寬自動縮小。
- 在目前瀏覽器自動儲存資料。
- 原生文字、表格與框線輸出，不使用圖片底圖。
- 列印使用固定毫米尺寸，避免螢幕預覽的縮放影響列印。

## 使用方式

直接開啟 `index.html`，或將本專案放到靜態網站服務。檔案須保持在同一個資料夾。

填寫後，按「列印完整表單」，並放入空白 A4 紙。列印設定：A4、直式、比例 100%、邊界「無」，關閉頁首及頁尾。

資料儲存於瀏覽器的 localStorage；更換裝置、瀏覽器或網址時不會同步。

## GitHub Pages

在專案的 Settings → Pages 選擇 Deploy from a branch，再選擇 `main` 與 `/(root)` 並儲存。是否可啟用依專案權限與 GitHub 帳號方案而定。

## 檔案

- `index.html`：填寫介面及完整表單。
- `styles.css`：預覽與 A4 列印樣式。
- `app.js`：填寫、明細、加總、勾選與本機儲存。

此版本為已確認可正常使用的列印修正版。
